# s9800-cooldown
STONKS-9800 mod that reduces the cooldown between company buyouts and mergers.

## Installation

### Steam Workshop
Subscribe to [Buyout & Merger Cooldown](https://steamcommunity.com/sharedfiles/filedetails/?id=3790505363) on the Steam Workshop and enable the mod from the **Mods** menu in-game.

### Manual
Download the [latest release](https://github.com/Joery/s9800-cooldown/releases/latest), copy `cooldown.meow` to the game's `mods` directory, then enable the mod from the **Mods** menu in-game.
